# Lightning Bet - Checklist de Implementação

- [x] Servidor Express com CORS

## 🔧 Configuração Necessária

Antes de rodar, configure o arquivo `backend/.env`:

```
ALBY_API_TOKEN=sua_chave_aqui
```

Obtenha em: https://getalby.com/developer/access_tokens

## 🚀 Para Rodar

```bash
# Configurar
vim backend/.env

# Instalar
npm install

# Inicializar DB
npm run init-db

# Rodar
npm run dev
```

Ou use o script:
```bash
./start.sh
```
