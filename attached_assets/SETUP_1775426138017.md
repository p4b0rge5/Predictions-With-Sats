# Lightning Bet - Setup Guide

## Prerequisites

- Node.js 20+
- Alby Account (https://getalby.com)
- (Optional) Docker & Docker Compose

## Step 1: Alby API Token

1. Go to https://getalby.com
2. Create an account
3. Navigate to Developer → Access Tokens
4. Create a new token with these permissions:
   - `invoices:read`
   - `invoices:create`
   - `payments:send`
   - `balance:read`

## Step 2: Configuration

1. Copy the example environment file:
```bash
cp backend/.env.example backend/.env
```

2. Edit `.env` and add your Alby token:
```bash
ALBY_API_TOKEN=your_token_here
```

## Step 3: Install Dependencies

```bash
cd backend
npm install
```

## Step 4: Initialize Database

```bash
npm run init-db
```

## Step 5: Start Development Server

```bash
npm run dev
```

The app will be available at `http://localhost:3000`

## Docker Deployment (Production)

```bash
# Build and start
docker-compose up -d

# View logs
docker-compose logs -f

# Stop
docker-compose down
```

## First Time Setup Checklist

- [ ] Alby account created with positive balance
- [ ] API token generated with correct permissions
- [ ] `.env` file configured
- [ ] Database initialized
- [ ] Webhook URL configured (for production)

## Webhook Configuration (Production)

In production, you need to configure Alby to send webhooks to your server:

1. Set `WEBHOOK_SECRET` in your `.env`
2. Configure webhook URL in Alby: `https://yourdomain.com/api/webhook/alby`
3. Alby will POST payment confirmations to this endpoint

## Troubleshooting

### "No valid price sources"
- Check internet connection
- Verify Binance/Coinbase/Kraken APIs are accessible

### "Failed to create invoice"
- Verify Alby API token is correct
- Check Alby account has sufficient balance

### Database locked
- Stop the server
- Delete `data/bets.db-shm` and `data/bets.db-wal`
- Restart

## Security Notes

- Never commit `.env` to git
- Use strong `WEBHOOK_SECRET` in production
- Enable HTTPS for production deployments
- Consider rate limiting for API endpoints
