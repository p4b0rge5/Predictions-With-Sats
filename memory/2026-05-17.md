## Sports WS Scores Module — Deployed

### Problem
The initial implementation of `sports-scores.ts` used `ws` package directly and had issues with process termination during hot reload (reconnect loop prevented clean shutdown).

### Solution
Created a new `sports-ws-scores.ts` module in `artifacts/api-server/src/lib/` that:
- Connects to `wss://ws-gateway.polymarket.com/ws/sports/v1`
- Subscribes to all live games
- Receives real-time score updates (homeScore, awayScore, period, status)
- Saves scores to `sport_poly_markets` DB table
- Proper cleanup on `SIGTERM` (closes WS connection, stops reconnect loop)
