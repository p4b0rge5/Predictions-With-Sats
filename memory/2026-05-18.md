# 2026-05-18

## Poly markets LIVE status fix (commit 8c6ff72e)

**Problem:** Polymarket sports markets that had already started (with live scores from WS) showed "EVENT IMMINENT" / "Betting closed — kickoff approaching" instead of "LIVE".

**Root cause:** `polyToSportEvent()` in `sports.tsx` mapped poly market status as:
- `settled` → `"finished"`
- `open` → `"upcoming"`

Poly markets only have two statuses (`open`/`settled`) — no native `"live"`. The old sports API had a `"live"` status, but poly markets didn't.

**Fix:** Detect live poly markets by checking if they have scores (populated by the WS scores module):
```ts
const isLive = !isSettled && m.homeScore != null && m.awayScore != null;
status: isSettled ? "finished" : isLive ? "live" : "upcoming",
```

This makes the frontend `ResultCard` show the red **LIVE** badge instead of yellow **EVENT IMMINENT**.

**Note:** Also fixed prod `.env` DATABASE_URL from `pwsats_dev` → `pwsats_db` (was pointing to non-existent database).
