## Active Work: Predictions-With-Sats - Sports Poly Markets API & UI

### Sports Poly Integration
- **External API**: `https://api.sports-poly.com` (Sports Poly odds data)
- **Endpoint**: `GET /api/sports-poly/markets` (server-side) → `GET /app/api/sports-poly/markets` (public)
- **API Key**: Stored in env variable `SPORTS_POLY_API_KEY`, read via `dotenv/config` in `config.ts`
- **Cache**: Server-side in-memory cache with configurable TTL (default 5 min)
- **Background enrichment**: `buildEnrichedMarkets()` enriches cached data with betting badges, league logos, and team logos
  - First request returns basic data immediately (`X-PWSats-Enriched: false`)
  - Enrichment runs in background, next request gets enriched data (`X-PWSats-Enriched: true`)
  - Enriched data includes: `bettingBadgeUrl`, `leagueLogoUrl`, `homeLogoUrl`, `awayLogoUrl`
  - Enrichment calls: The Odds API (betting badges + league logos) + API Ball (team logos)

### URL Configuration
- **The Odds API key**: Set via `THE_ODDS_API_KEY` env var, read in `config.ts`
- **API Ball key**: `450a83f2774546c7992c0d1b923950d2` (stored in `.env`)
- **Team logo URL pattern**: `https://api.api-sports.io/v3/teams/logo?id={teamId}`
- **League logo URL pattern**: `https://www.the-odds-api.com/api/sports/logos/{sportKey}/{leagueKey}/logo.png`
- **Betting badge URL pattern**: `https://www.the-odds-api.com/api/sports/logos/{sportKey}/{bookKey}/badge.svg`

### UI Component: SportPolyMarketsTable
- Location: `src/components/sports-poly/SportPolyMarketsTable.tsx`
- Displays: Sport, League, Home Team (with logo), Away Team (with logo), Spread, Moneyline, Total (Over/Under), Betting Site badges
- Column order: Sport → League → Home → Away → Spread → Total Over → Total Under → Moneyline Home → Moneyline Away → Betting Sites
- Uses `<img>` with fallback for logos/badges (onError hides broken images)

### Route: sports-poly.ts
- Location: `artifacts/api-server/src/routes/sports-poly.ts`
- Fetches from Sports Poly API
- Normalizes into: `SportPolyMarket` type (sportKey, sportTitle, league, eventId, homeTeam, awayTeam, commencingAt, bookmakers)
- Enriched type: `SportPolyMarketEnriched` extends `SportPolyMarket` with optional logo/badge URLs
